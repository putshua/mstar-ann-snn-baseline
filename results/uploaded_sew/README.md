## 为什么稀疏版更快

稀疏版加速来自减少计算和数据搬运：普通 cuDNN 仍然计算完整卷积输出，随后 mask 把大部分结果清零；稀疏 kernel 预先从固定 mask 生成活跃输出坐标，只计算这些坐标上的卷积点积，并在同一路径中完成 BN、四步 LIF 和残差。

全零中间通道同步从前后两层卷积中移除；整段零输入分支在计入 BN 偏置后预计算为常量。空间 mask 的剩余部分通过坐标索引执行，不直接折成共享卷积权重。

相对已经融合的 bn_lif 版本，三个稀疏版本分别再减少约 13.4%、21.0%、20.6% 的延迟；4.1–4.5× 是相对原始未优化图的总加速，包含神经元和算子融合的贡献。

稀疏点积的浮点累加顺序与 cuDNN 不同，阈值可放大舍入差异。本次三组 sparse 相对对应 BS=1 基线分别少分对 2 / 4 / 3 张，Accuracy 下降 0.0825 / 0.1649 / 0.1237 个百分点；bn_lif 在这四组权重上保持原始 BS=1 Accuracy。

## 时间口径

这组实验使用同轮原始模型计算加速比。旧报告的 ANN 均值 1.9864 ms 来自上一轮，P50=1.4587 ms、P95=4.5600 ms；本轮 ANN 原始图均值 1.4615 ms、Conv-BN 折叠后 1.0158 ms。旧均值包含较大的长尾波动，不能和新融合时间交叉计算加速比。

旧报告的分类 batch 为 64，本组为 1。SNN 阈值可能放大不同 batch 卷积的舍入差异，因此 Accuracy 应与本表对应的 BS=1 原始图比较。新增 checkpoint 暂不上传，后续可单独打 zip。
